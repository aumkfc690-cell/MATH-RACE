PERCENT RACE - วิธีเปิดเกม

1) แตกไฟล์ ZIP
2) เปิด VS Code
3) เลือก File > Open Folder แล้วเลือกโฟลเดอร์ PERCENT-RACE
4) เปิดไฟล์ index.html ในเบราว์เซอร์ได้เลย
   หรือใช้ส่วนขยาย Live Server แล้วคลิกขวา index.html > Open with Live Server

ไฟล์:
- index.html : โครงหน้าเกม
- style.css : รูปแบบและการรองรับมือถือ
- script.js : ระบบกระดาน ผู้เล่น บอท ร้านค้า และการเดินเกม
- questions.js : ชุดคำถามตัวอย่างเรื่องร้อยละ

หมายเหตุเรื่องโจทย์:
ลิงก์แชร์ที่ส่งมาแสดงเพียงชื่อหน้าแชต แต่ไม่แสดงเนื้อหาโจทย์ในระบบ จึงใส่โจทย์ตัวอย่างเรื่องร้อยละไว้ก่อน
เมื่อส่งภาพหรือคัดลอกโจทย์จากลิงก์มา จะสามารถแทนที่ชุดคำถามใน questions.js ได้

เกมเวอร์ชันนี้เป็นต้นแบบเล่นในเครื่องเดียว ผู้เล่น 1 คนแข่งกับบอท 3 ตัว ยังไม่มีระบบออนไลน์เล่นกับเพื่อน
